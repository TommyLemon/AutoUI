# AutoUI-Admin

### 前端
src/main/resources/static 内 Vue.js + Axios + Editor.md + Bootstrap 实现管理后台网页，<br />
原名 UIGO-Admin，属于 UIGO 内部的管理后台网页，当时功能简陋未和其它部分一起开源，<br />
现已大幅完善功能和体验，并重命名为 AutoUI-Admin 开源出来。

### 后端
APIJSON + SpringBoot 实现 Java 后端接口服务，基于 APIJSONBoot-MultiDataSource 简化而来<br />

### 运行

右键 AutoTestApplication > Run As > Java Application

点击控制台日志内输出链接，或直接点以下链接<br />

http://localhost:8080

右上角设置 托管服务器代理 为 本地 http://localhost:8080 或 官网 http://apijson.cn:8080 ，<br />
![](https://github.com/user-attachments/assets/d15b9929-03b9-44e3-b105-660a68c6dede)

右上角登录(可用已自动填充的默认帐号及密码)，按照网页提示来查看用例、录制用例、回放用例、查看断言、调整断言 等。
